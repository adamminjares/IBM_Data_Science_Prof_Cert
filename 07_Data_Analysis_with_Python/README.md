# 07 — Data Analysis with Python

Coursework focused on the end-to-end process of acquiring, cleaning, exploring, visualizing, and modeling data using Python.

## Topics & Skills

- Data acquisition
- Data wrangling and cleaning
- Data formatting and transformation
- Exploratory data analysis (EDA)
- Statistical analysis
- Data visualization
- Correlation analysis
- Linear regression
- Multiple linear regression
- Polynomial regression
- Model development
- Model evaluation and refinement
- Data pipelines
- Regularization
- Predictive modeling

## Coursework

Hands-on exercises and projects applying the data analysis workflow to datasets involving used cars, laptop pricing, insurance costs, and residential property sales.

## Tools

**Python · Pandas · NumPy · Matplotlib · Seaborn · SciPy · Scikit-learn · Jupyter Notebooks**
