# 05 — Python Project for Data Science

A project-based course applying foundational Python and data science skills to the extraction, analysis, and visualization of real-world financial data.

## Topics & Skills

- Data extraction
- Web scraping
- HTML parsing
- Financial data
- Stock data
- Pandas
- Data visualization
- Identifying patterns and trends
- Dashboard development

## Coursework

Hands-on project work involving the extraction of stock and revenue data, web scraping, data processing, visualization, and the development of an interactive dashboard.

## Tools

**Python · Jupyter Notebooks · Pandas · BeautifulSoup · Plotly · Dash**
