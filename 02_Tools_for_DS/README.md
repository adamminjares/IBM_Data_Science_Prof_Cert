# 02 — Tools for Data Science

Coursework introducing the tools and environments commonly used by data science professionals, with hands-on practice using Jupyter Notebooks and related data science tooling.

## Topics & Skills

- Data Scientist's toolkit
- Jupyter Notebooks and JupyterLab
- Notebook creation, organization, and documentation
- Markdown
- Kernels and notebook environments
- Data science libraries and packages
- Open-source and commercial data science tools
- Git and GitHub
- Cloud-based data science environments
- Working with Python, R, and Scala

## Coursework

Hands-on exercises focused primarily on working with Jupyter Notebooks, including creating and organizing notebooks, writing Markdown, working with files, and preparing notebooks for sharing.

## Tools

**Jupyter Notebooks · JupyterLab · Git · GitHub · Python**
