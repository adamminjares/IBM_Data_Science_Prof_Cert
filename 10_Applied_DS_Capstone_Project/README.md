# 10 — Applied Data Science Capstone

The capstone project for the **IBM Data Science Professional Certificate**, applying the data science workflow to a real-world-inspired aerospace problem: predicting whether the first stage of a SpaceX Falcon 9 rocket will land successfully.

## Project Workflow

- Data collection
- Web scraping
- Data wrangling
- Exploratory data analysis
- SQL-based analysis
- Data visualization
- Interactive visual analytics
- Model development
- Model evaluation
- Reporting findings to stakeholders

## Project

The project follows the role of a data scientist working for a startup seeking to compete with SpaceX. Launch data is collected from multiple sources, cleaned and analyzed, and used to identify factors associated with successful first-stage landings.

The analysis combines Python, SQL, exploratory analysis, visualization, and machine learning techniques developed throughout the preceding courses.

## Tools

**Python · Pandas · SQL · SQLite · BeautifulSoup · Matplotlib · Seaborn · Folium · Scikit-learn · Jupyter Notebooks**
