# 09 — Machine Learning with Python

Coursework covering supervised and unsupervised machine learning techniques, with an emphasis on building, evaluating, and optimizing models using Python and scikit-learn.

## Topics & Skills

- Supervised learning
- Unsupervised learning
- Linear regression
- Multiple linear regression
- Logistic regression
- Multiclass classification
- Decision trees
- Regression trees
- Support vector machines (SVM)
- K-nearest neighbors (KNN)
- Random forests
- XGBoost
- K-means clustering
- DBSCAN and HDBSCAN
- Principal component analysis (PCA)
- t-SNE and UMAP
- Model evaluation
- Cross-validation
- Regularization
- Machine learning pipelines
- Hyperparameter optimization
- GridSearchCV

## Coursework

Hands-on exercises progressing from foundational regression and classification techniques through tree-based models, ensemble methods, clustering, dimensionality reduction, model evaluation, regularization, and pipeline optimization.

The course concludes with a practice project involving Titanic survival prediction and a final project developing a rainfall prediction classifier.

## Tools

**Python · Scikit-learn · Pandas · NumPy · Jupyter Notebooks**
