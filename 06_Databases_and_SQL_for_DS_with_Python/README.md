# 06 — Databases and SQL for Data Science with Python

Coursework developing practical SQL and database skills for querying, managing, and analyzing data, including accessing databases from Python and Jupyter Notebooks.

## Topics & Skills

- Relational databases
- SQL fundamentals
- `SELECT`, `INSERT`, `UPDATE`, and `DELETE`
- Filtering and sorting
- Aggregate functions
- `GROUP BY` and `ORDER BY`
- String patterns and ranges
- Database functions
- Subqueries
- Multiple-table queries
- Joins
- Database schema and table management
- DDL and DML
- SQLite
- SQL Magic
- Accessing databases with Python
- Analysis of real-world datasets

## Coursework

Hands-on SQL exercises progressing from foundational queries to database analysis using SQLite, SQL Magic, Python, and multiple real-world datasets.

## Tools

**SQL · SQLite · Python · Jupyter Notebooks**
