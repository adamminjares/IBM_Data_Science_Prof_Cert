# 08 — Data Visualization with Python

Coursework focused on using Python visualization tools to explore data, communicate findings, and develop interactive visual analytics and dashboards.

## Topics & Skills

- Data visualization principles
- Matplotlib
- Line plots
- Area plots
- Histograms
- Bar charts
- Pie charts
- Scatter plots
- Box plots
- Bubble plots
- Waffle charts
- Word clouds
- Regression plots
- Geospatial visualization
- Interactive visualization
- Interactive dashboards
- Data storytelling

## Coursework

Hands-on visualization exercises progressing from foundational charts to geospatial visualization, interactive graphics, and dashboard development. Practice and final projects apply these techniques to real-world datasets, including Australian wildfire data.

## Tools

**Python · Matplotlib · Seaborn · Folium · Plotly · Dash · Jupyter Notebooks**
